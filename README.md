# Claudian Schedule — отложенные сообщения Клодиану

Плагин Obsidian. Пишешь сообщение сейчас, указываешь время — плагин сам кладёт его
в чат [Claudian](https://github.com/YishenTu/realclaudian) и отправляет. Как будто ты
набрал текст и нажал Enter, только в назначенный час.

Зачем: поставить работу на ночь или на утро («в 6:00 собери, что горит по проектам»),
вернуться к теме через час, не держа это в голове, отложить вопрос на рабочее время.

## Как пользоваться

| Действие | Как |
|---|---|
| Отложить то, что уже набрано в поле Клодиана | Кнопка **⏰** в панели ввода |
| Отложить новое сообщение | `Cmd+P` → «Отложить сообщение Клодиану» |
| Посмотреть очередь | Счётчик **⏰ N** внизу окна (клик) или `Cmd+P` → «Отложенные сообщения — список» |
| Отправить раньше срока / перенести / удалить | Кнопки в списке |

Время пишется по-человечески:

```
через 30 минут      через 2 часа      через 1,5 часа      через 3 дня
сегодня 18:00       завтра 9:00       послезавтра 7:30
18:00               26.09 18:30       2026-09-25 07:15
```

«18:00», когда уже вечер, означает завтра — в прошлое плагин не отправляет и
непонятный ввод не проглатывает: скажет, чего не понял.

## Что происходит в назначенное время

1. Окно Клодиана закрыто — плагин откроет его сам.
2. Агент дописывает ответ — **ждать не нужно**: Клодиан сам ставит сообщение в очередь
   и показывает это строкой «⌙ Queued». Плагин различает исходы «ушло» и «в очереди»
   и не выдаёт очередь за отказ.
3. В поле ввода твой черновик — **он не тронут**, сообщение уйдёт в новую вкладку.
4. Отправка считается удавшейся, только если сообщение реально появилось в переписке
   (или встало в очередь). Не появилось — статус «не удалось», причина в уведомлении
   и в журнале `schedule.log`. Временная помеха (Клодиан ещё не поднялся) — не отказ:
   плагин вернётся на следующем ходу часов, до 20 попыток.

## Обсидиан был закрыт

Плагин живёт внутри Обсидиана: **приложение закрыто — никто ничего не отправит.**
При следующем запуске он смотрит, что проспал:

- опоздание меньше запаса (по умолчанию 12 часов) — отправляет;
- больше — помечает «просрочено» и показывает в списке, чтобы решить самому.

Спящий Мак — тот же случай: проверка просрочки живёт в обычном ходе часов, а не только
в запуске Обсидиана, поэтому после пробуждения она отработает так же.

## Установка

Для разработки:

```bash
bash install.sh /путь/к/хранилищу
```

Скрипт проверит синтаксис, скопирует файлы, сверит их слепки и включит плагин в списке.
Потом перезапустить Obsidian (`Cmd+Q` и открыть заново).

## Проверки

```bash
npm test                    # все три набора разом, 65 проверок
node test/when.test.js      # разбор времени и отказ от бессмыслицы
node test/deliver.test.js   # доставка в чат на настоящем дереве страницы (jsdom)
node test/overdue.test.js   # очередь, просрочка, замок от двойной отправки
```

Установить jsdom: `npm i -D jsdom`.

Поддельный Клодиан для проверок — `test/_claudian.js`. Каждое его свойство сверено
с настоящей сборкой 2.2.6 и помечено в шапке файла. Это важнее, чем кажется:
до ревизии 24.09.2026 заготовка повторяла домыслы автора, и проверки были зелёными
при сломанной защите.

## Как устроен стык с Клодианом

Отдельного программного входа у Клодиана нет, поэтому работаем через интерфейс —
те же опорные точки, что уже проверены плагином Claudian Voice:

| Что | Как берём |
|---|---|
| Окна (включая оторванные) | `app.workspace.getLeavesOfType('claudian-view')` → `leaf.view.containerEl` |
| Вкладка | `.claudian-tab-content`; неактивные скрыты классом `.claudian-hidden` |
| Поле ввода | `textarea.claudian-input` внутри вкладки |
| Сообщения пользователя | `[data-role="user"]` (класс `.claudian-message-user` — запасной) |
| Очередь при занятом агенте | `.claudian-input-queue-row` — «⌙ Queued: …» |
| Панель ввода | `.claudian-input-toolbar` |
| Команды | `<id>:open-view`, `<id>:new-tab` — id ищется среди зарегистрированных (форк `realclaudian`, апстрим `claudian`) |

**Чего специально НЕ делаем:** не определяем занятость по бейджу вкладки.
Активная вкладка получает класс `-active`, а `-streaming` достаётся только неактивной —
то есть «агент печатает» по бейджу в своей же вкладке не видно никогда.

Если очередное обновление Клодиана переименует классы — доставка не «сделает вид»,
а честно упадёт с причиной: в тестах на это есть отдельное учение.

## Чего пока нет

Повторяющихся сообщений («каждый будний день в 9:00»). Решение владельца 24.09.2026 —
сначала обкатать разовые.
